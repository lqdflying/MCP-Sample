# GitHub OAuth Callback Guide

This guide explains which callback URL to use when connecting this MCP server to GitHub OAuth, especially for Power Automate custom connectors.

## Choose the Correct Callback URL

The callback URL depends on which OAuth flow is driving the sign-in.

### 1. Power Automate Custom Connector OAuth (recommended for Power Automate)

Use the redirect URL generated by Power Automate after you save or update the custom connector.

- In Power Automate custom connector Security tab, choose OAuth 2.0 and GitHub.
- Save or update custom connector.
- Copy the generated Redirect URL.
- In your GitHub App settings, add this URL to the callback URLs list.

For this flow, GitHub redirects back to Power Automate, then Power Automate sends bearer tokens to this MCP server. The server validates them via `GitHubTokenVerifier` (Step 3 of `MultiAuth`).

### 2. OAuth 2.1 Proxy Flow (VS Code, Cursor, direct server-driven OAuth)

Use this server callback path:

```
https://your-domain/auth/callback
```

This flow uses FastMCP's built-in `GitHubProvider` as an OAuth 2.1 proxy with DCR, PKCE, and CIMD. The server manages the full OAuth lifecycle.

## Callback URL Setup

A single GitHub App can support **up to 10 callback URLs**. You do not need separate apps — add both URLs to the same App:

```
https://your-domain/auth/callback                              ← Server OAuth 2.1 proxy
https://global.consent.azure-apim.net/redirect/<connector-id>  ← Power Automate
```

## Recommended Setup

For a deployment supporting both flows:

1. Register a GitHub App with both callback URLs above.
2. Set up `.env`:

```env
MCP_AUTH_MODE=both
MCP_API_TOKEN=<generate-a-strong-token>
GITHUB_CLIENT_ID=<your-app-client-id>
GITHUB_CLIENT_SECRET=<your-app-secret>
BASE_URL=https://your-public-mcp-domain
ALLOWED_GITHUB_LOGINS=<your-github-login>
# Optional: persistent OAuth storage across restarts
# FASTMCP_HOME=/var/lib/mcp-auth-sample/fastmcp
```

3. **For Power Automate only**: use `MCP_AUTH_MODE=token` with just `MCP_API_TOKEN` if you don't need OAuth.
4. **For VS Code/Cursor only**: use `MCP_AUTH_MODE=oauth` to disable static token auth.

## OAuth Storage

OAuth state (client registrations, tokens, sessions) is stored by FastMCP at
its configured home directory. Set `FASTMCP_HOME` to a writable directory for
**persistent encrypted file storage** that survives restarts. In Docker, mount
a volume at that path:

```yaml
services:
  mcp-auth-sample:
    environment:
      - FASTMCP_HOME=/data/fastmcp
    volumes:
      - mcp-oauth-data:/data/fastmcp

volumes:
  mcp-oauth-data:
```
